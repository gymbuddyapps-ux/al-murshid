# Vocabulary audit (Phase 0)

This file is generated by `scripts/audit/build_vocab_audit.py`. All counts come from the JSON files in `reports/audit/`.

## 1. Summary

- **Neither primary dataset could be used.** ArabicSL-Net is private, and the Zenodo "Arabic words sign language video dataset" record contains only a tiny sample.
- **The fallback, KArSL-502, is the only listed source with usable data.** It is used for everything.
- **KArSL has no fruit, vegetable or shopping words** (no "want", "kilo", "price", "how much").
- **The scenario was therefore changed from a grocery to a pharmacy**, which is still a "customer talks to a seller" situation and is well covered by KArSL's health chapter.
- **Signer IDs exist**: 3 signers (IDs 1, 2, 3). This allows leave-one-signer-out evaluation in Phase 3.
- **23 classes are in the current vocabulary** (section 5, `config/vocab.json`).

### How KArSL was obtained

- The official download links point to a university SharePoint. They returned an error page to scripted downloads, so a public Kaggle copy was used instead: `yousefdotpy/karsl-502` (video frames, 256x256 pixels, same folder layout as the official release: signer / split / sign ID / sample).
- The label sheet `KARSL-502_Labels.xlsx` (SignID, Arabic, English) came from the Kaggle copy `d3vl0per/karsl-502-labelss`.
- Per-sample counts and signer IDs came from `metadata.json` in the Kaggle copy `tfmohamedyahia/kars502-pose-75`. These counts are re-checked against the downloaded frames in Phase 1.
- Kaggle shows the license of the frame copy as "unknown". The KArSL authors ask for a citation (see `CREDITS.md`).

## 3. Signer IDs

- **KArSL:** yes. Every sample belongs to signer 1, 2 or 3, and the signer is part of the folder and file name. All 502 signs were recorded by all 3 signers.
- **ArabicSL-Net and the Zenodo dataset:** could not be checked, because the data is not available.
- **Consequence for Phase 3:** leave-one-signer-out evaluation is possible, but with only 3 signers. One signer is used for training, one for validation (tuning) and one is held out for the final test.

## 4. Things to know about KArSL before trusting the demo

- It was recorded with a Kinect camera in a studio (seated signer, plain green background), not with a phone. The app will be used with a phone camera, so real-world accuracy can be lower.
- Only 3 signers. A model can look good on these 3 people and still struggle with a new person.
- The signs follow the unified Arabic sign language dictionary. Signs used in Oman may differ.
